数据处理说明

DeepSeek Harness 是本地优先、可扩展的 Coding Agent 与 Agent 开发运行环境。产品安装运行后，默认在用户本地设备上处理、存储以下数据，未经用户的同意不会上传到服务端，这些数据包括：

  • 用户的输入、模型的输出以及 session 其他上下文内容
  • Agent 工具调用记录、附件、文件路径、执行结果以及运行日志
  • 用户自行配置的模型服务地址、API key 以及任何个人身份信息

为了排查定位问题、改进优化产品，我们可能会上报经过脱敏处理后的配置信息和项目清单，用户可以选择关闭或修改上报地址。

特别说明，当用户使用 DeepSeek Harness 主动配置、调用其他外部模型、网络工具、MCP服务或插件等服务、工具时，这些服务或者工具可能会上报用户数据，这些数据完全由被调用的服务方处理，相应数据处理、收集的情况请查阅对应服务提供方的数据处理政策。

如对本说明或 DeepSeek Harness 的数据处理活动有任何疑问，请通过 harness-privacy@deepseek.com 联系我们。
